Five algorithms over the same set of freshly generated mazes, run in a worker thread pool so the results are averages rather than one lucky maze. The seed comes back with the numbers, so any run can be repeated.

Drag on the grid to draw walls. Hold Shift while dragging to lay slow ground — Dijkstra and A* will route around it, breadth-first will walk straight through and pay for it. Drag the green and red squares to move the start and goal.

A* expands toward the goal first using a Manhattan estimate, so it visits far fewer cells than Dijkstra while still returning a shortest path.
